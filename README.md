# LJT-Homepage

Personal academic homepage of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Where the content lives

- `_pages/about.md` - home page (personal details, education, research experience, publications, skills and contact information)
- `_publications/` - one Markdown file per publication, listed on the `/publications/` page
- `_config.yml` - site-wide configuration (site title, sidebar profile and links)
- `_data/navigation.yml` - top navigation menu

## Local preview

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```
